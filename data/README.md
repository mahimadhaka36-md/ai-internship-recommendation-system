# Datasets

Dataset files used by the AI Internship Recommendation System:

- `technical_internships_ready.csv`: 388 technical internship listings (title, location, stipend range, required skills, type, and cleaned skill tokens) used for catalog browsing and TF-IDF + Cosine Similarity recommendations.
- `synthetic_student_profiles_30.csv`: 30 fictional synthetic student demo profiles (academic major, university year, CGPA & scale, technical skills, proficiency ratings, projects, certifications, prior internships, career field, technical domain, and internship role) used for KNN-based peer matching in **Explore Profiles**.
